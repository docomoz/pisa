# Pisya

**Рекордер встреч для Mac с локальной расшифровкой.** Записывайте разговоры, находите нужные фрагменты и сохраняйте текст в Markdown.

Pisya работает на Mac с Apple Silicon и macOS 15 или новее. Приложение находится на ранней стадии разработки.

## Возможности

- **Запись встреч.** Pisya записывает микрофон и системный звук на отдельные дорожки. Запись можно начать до звонка и использовать с любым приложением или браузером.
- **Расшифровка на Mac.** Распознавание речи и обработка звука выполняются локально. Во время встречи может появляться черновик; после записи Pisya обрабатывает оставшееся аудио.
- **Участники.** Можно прослушать фрагменты, исправить имена и сохранить образцы голосов для следующих встреч.
- **Библиотека.** Записи можно искать, редактировать, раскладывать по папкам и восстанавливать из корзины.
- **Markdown.** Готовые расшифровки можно автоматически сохранять в выбранную папку, например в хранилище Obsidian.
- **Доступ через MCP.** Локальный клиент может искать встречи и читать расшифровки, если вы отдельно включите доступ в настройках.

## Приватность

Запись, библиотека и распознавание находятся на вашем Mac. Приложение работает в App Sandbox. Интернет нужен для загрузки моделей с Hugging Face при первой настройке; аудио и расшифровки для распознавания не отправляются.

Если выбрать папку, синхронизируемую через iCloud, Dropbox или другой сервис, экспортированные тексты могут попасть в облако. При использовании MCP подключённый клиент также может передать прочитанный текст своему провайдеру. Обе возможности включаются отдельно.

Голосовые образцы хранятся отдельно от аудио встреч. Удаление аудио встречи не удаляет сохранённые образцы голосов. Отдельного пароля для библиотеки нет: её защита зависит от учётной записи macOS, прав файлов и FileVault.

## Сборка

Для сборки из исходников понадобятся Mac с Apple Silicon, macOS 15+, Xcode с Metal Toolchain, XcodeGen и Python 3.9 или новее.

```sh
git clone --recurse-submodules https://github.com/docomoz/pisya.git
cd pisya
./scripts/build.sh
```

Сборка создаёт приложение `build/Build/Products/Release/Pisya.app` и оформленный установочный образ `build/Pisya-<версия>-arm64.dmg`. В образе есть приложение и ссылка на Applications. Нативные библиотеки, Metal-ресурсы и помощник MCP уже включены в приложение. Пользователю готовой сборки не нужны Xcode, Homebrew или Python.

Если Metal Toolchain не установлен, его можно загрузить командой:

```sh
xcodebuild -downloadComponent MetalToolchain
```

Для запуска тестов ядра:

```sh
swift test
```

По умолчанию используется временная подпись приложения. После пересборки macOS может повторно запросить разрешения. Для распространения на другие Mac необходимы Developer ID и нотариальное заверение Apple.

## Начало работы

1. Откройте DMG и перетащите Pisya в Applications. Запустите приложение из этой папки.
2. Нажмите «Загрузить модели» в окне первой настройки. Понадобится около 3 ГБ свободного места. Загрузка показывает прогресс; её можно отменить и повторить. Уже проверенные файлы сохраняются, незавершённый файл загружается заново.
3. Начните запись и разрешите доступ к микрофону и системному звуку, когда macOS попросит. Нажмите «Начать запись» до начала звонка или во время разговора. Для начала проверьте работу на короткой встрече.
4. После обработки проверьте расшифровку и имена участников. При необходимости настройте экспорт в Markdown.

Настройку моделей можно отложить и вернуться к ней в разделе «Модель». Без моделей запись и импорт сохраняют аудио, а расшифровка станет доступна после установки. Существующая папка Qwen3-ASR поддерживается; при необходимости Pisya загрузит только модели участников. Скрипт `scripts/install-model.py` оставлен как дополнительный способ установки для разработчиков.

Pisya не удаляет аудио автоматически. Удалить его можно вручную после проверки текста; при импорте исходный файл остаётся на месте.

## Что важно учитывать

- Распознавание и определение говорящих могут ошибаться, особенно если люди говорят одновременно или реплики очень короткие. Проверяйте расшифровку перед использованием.
- Автоматический запуск записи экспериментальный и по умолчанию выключен. Он ориентируется на использование микрофона другими приложениями, поэтому возможны ложные срабатывания.
- Эхоподавление зависит от микрофона, динамиков и условий записи. Исходные дорожки сохраняются.
- Доступ через MCP выключен по умолчанию. После включения клиент может использовать инструменты `list_meetings`, `search_meetings` и `read_transcript`. Отключить доступ можно в настройках.

## Технологии и зависимости

Приложение написано на Swift и SwiftUI. Для локального распознавания используются Qwen3-ASR и MLX Audio Swift; для обработки и разметки звука — WebRTC AEC3, Silero VAD и Sherpa ONNX. Лицензии сторонних компонентов находятся рядом с соответствующими файлами. Веса моделей распространяются отдельно на условиях их авторов.

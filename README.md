# Pisya

Автор: Максим Берёзкин — maxim@berezkin.ru

Личный рекордер встреч для Mac: запись звонков, локальная расшифровка, участники и Markdown. SwiftUI, macOS 15+, Apple Silicon. Версия 0.4.0.

## Что внутри

- Запись микрофона через отдельную AVCaptureSession и системного звука через ScreenCaptureKit. Дорожки сохраняются раздельно и синхронизируются по часам macOS.
- Запись всего системного звука и микрофона: можно начать до открытия звонка в любом приложении или браузере.
- Отдельный экспериментальный автодетект использования микрофона другими приложениями; старт через 3 секунды, стоп через 45 секунд после завершения активности.
- Импорт аудиофайлов, локальный Qwen3-ASR, разметка Pyannote/TitaNet, именованные голосовые профили.
- Поиск, редактирование реплик и имён, воспроизведение фрагментов, удаление аудио после проверки текста.
- Автоэкспорт Markdown в выбранную папку, включая Dropbox и Obsidian.
- Локальный MCP через stdio: список, поиск и чтение встреч. По умолчанию выключен.

## Первый запуск

1. Откройте приложение. Нажмите «Записать» до или во время звонка — выбор приложения не требуется.
2. Установите модели отдельным скриптом `python3 scripts/install-model.py` или выберите готовую папку Qwen3-ASR в настройках. Модели занимают около 2,6 ГБ. Скрипт проверяет SHA-256 каждого файла.
3. При первой записи разрешите микрофон и захват системного звука в macOS.
4. Проверьте короткий звонок с гарнитурой, затем включите автозапись в настройках.
5. Для выгрузки выберите папку. Текст обновляется после обработки и последующих правок.

Автоматического удаления аудио нет: сначала убедитесь, что расшифровка верна. После этого аудио можно удалить через меню встречи. Импорт копирует исходный файл, не удаляя оригинал.

## Приватность

Основное приложение подписывается с App Sandbox **без сетевых разрешений**. Оно читает локальные модели; сетевой загрузчик вынесен в отдельный скрипт. Библиотека — в собственном контейнере приложения. Модель не является сервисом, которому отправляется аудио.

Папка Dropbox/iCloud означает передачу экспортированного текста этому сервису. MCP-клиент может передать прочитанный текст своему провайдеру. Эти действия включаются отдельно. Голосовые признаки не включаются в Markdown и ответы MCP.

Не заявляется шифрование библиотеки отдельным паролем: её защита зависит от учётной записи macOS, прав файлов и FileVault. App Sandbox ограничивает само приложение и не делает пользовательские данные недоступными всем другим процессам.

## Сборка

Нужны Xcode с Metal Toolchain, XcodeGen и Python 3.9+ для скрипта моделей.

```sh
git clone --recurse-submodules https://github.com/docomoz/pisya.git
cd pisya
./scripts/build.sh
```

Если Metal Toolchain отсутствует:

```sh
xcodebuild -downloadComponent MetalToolchain
```

Сборка: `build/Build/Products/Release/Pisya.app`. Подмодуль MLX Audio зафиксирован на конкретном коммите; остальные разрешённые версии зафиксированы в dependencies.resolved.json (скрипт копирует его в Package.resolved). Сборка не включает веса моделей, записи и персональные настройки.

```sh
swift test
```

## MCP

Включите доступ в настройках приложения и скопируйте показанную конфигурацию. Исполняемый файл — `Pisya.app/Contents/Helpers/pisya-mcp`. Поддерживается MCP stdio с handshake протоколов 2024-11-05, 2025-03-26, 2025-06-18 и 2025-11-25.

Инструменты: `list_meetings`, `search_meetings`, `read_transcript`. Чтение расшифровки разбито на страницы по 100 реплик. Доступ проверяется при каждом запросе и отзывается переключателем в приложении. Клиенты, поддерживающие исключительно новые несовместимые версии MCP, не проверены.

## Ограничения ранней версии

Автодетект определяет использование микрофона другим приложением, а не состояние звонка: возможны ложные старты и остановки. Тест микрофона может выглядеть как звонок. Настоящий звонок, mute, гарнитуры и переподключение необходимо проверить вручную.

Разметка и узнавание голосов вероятностные. Перекрывающаяся речь и очень короткие реплики могут размечаться неверно. Сохраняйте профиль только после проверки реплик. Это не биометрическая аутентификация. Распознавание обрабатывает звук порциями; метки относятся к фрагментам, а не к каждому слову.

Для локальной разработки поддерживается постоянная подпись сертификатом: создайте исключённый из Git файл `.signing.env` с `PISYA_SIGNING_IDENTITY` и абсолютным путём `PISYA_SIGNING_KEYCHAIN`. Связка ключей должна быть разблокирована перед сборкой. Без конфигурации используется временная ad hoc подпись, которая может сбрасывать разрешения macOS при обновлениях. Закрытый ключ и связку ключей нельзя добавлять в репозиторий. Для беспрепятственной установки на других Mac потребуются Developer ID и notarization. Саммари в эту версию не входит.

## Зависимости

- MLX Audio Swift и MLX Swift — открытые библиотеки локального распознавания; лицензии в подмодуле и пакетах.
- Sherpa ONNX 2.0.1 — Apache-2.0; заголовок и лицензия в Vendor/Sherpa. Библиотеки загружаются сборочным скриптом по фиксированной версии и контрольной сумме.
- ONNX Runtime — MIT, поставляется в сборке Sherpa ONNX.
- Веса Qwen3-ASR, TitaNet и Pyannote распространяются отдельно, по условиям их авторов и соответствующих репозиториев моделей.

Во время записи показываются живые уровни микрофона и системного звука, длительность записанных данных каждой дорожки и состояние потока. Волна рассчитывается по аудиобуферам после успешной записи в файл; отсутствие новых буферов отличается от тишины.

## Библиотека и голоса · 0.2

- Правая кнопка по записи: переименовать, переместить в папку, разметить голоса, отправить в корзину. Корзина поддерживает восстановление. «Очистить корзину» по правой кнопке удаляет её записи и аудио после подтверждения. Уже экспортированные Markdown-файлы не удаляются автоматически.
- Папки имеют один уровень. При удалении папки записи переходят в «Без папки».
- Поиск слева работает по названию, заметкам, участникам и тексту в текущем разделе. Для поиска по всей библиотеке выберите «Все записи». В открытой встрече есть отдельный поиск по репликам.
- В «Голосах» выберите и прослушайте фрагмент, назначьте имя одной реплике или всей группе. «Запомнить голос» сохраняет локальный аудиообразец до 8 секунд и слепок для следующих расшифровок. Сохранённые образцы можно слушать в этом же окне.
- Сохранённые голоса отделены от аудио встреч. Исправление того же обучающего фрагмента убирает прежнее назначение образца. Автоматическое распознавание имён остаётся экспериментальным: неоднозначные совпадения не назначаются.
- Волна измеряет данные с частотой 30 Гц, но прокручивается на отдельной шкале анимации с целевой частотой 60 кадров/с. Реальная частота зависит от нагрузки и режима экрана.

## Обработка звука · 0.4

Перед распознаванием микрофон проходит адаптивное эхоподавление WebRTC AEC3 с системной дорожкой как опорным сигналом. Выравнивание учитывает изменения задержки между дорожками. Используется линейный выход фильтра: дополнительное подавление остаточного эха могло удалять тихие короткие ответы. Исходные дорожки сохраняются, старые расшифровки автоматически не переписываются. Эффективность зависит от акустики, громкости динамиков и микрофона.

Фоновая расшифровка обрабатывает подтверждённые участки во время звонка и сохраняет черновик. После остановки обрабатывается оставшийся хвост и уточняется разметка собеседников. Обработка идёт последовательно с повторным использованием модели; её можно приостановить отдельно от записи. При сильном нагреве фоновая обработка откладывается. Это распределяет нагрузку по времени, но не гарантирует меньший общий расход энергии. Если системная дорожка ещё не подтвердила временную границу или непрерывная реплика длиннее 60 секунд, соответствующий участок может ждать завершения записи.

Silero VAD определяет участки речи на обработанном микрофоне, чтобы распознаватель не создавал текст из остаточного шума. Модель входит в приложение и работает локально. Системная дорожка размечается по голосам в более длинных окнах; участники объединяются по обновляемым центроидам всей встречи. Короткие и неоднозначные фрагменты могут остаться без индивидуального имени.

«Тихая обработка» в настройках модели включена по умолчанию: CPU-разметка использует два потока, между фрагментами распознавания добавляются паузы, при перегреве паузы сохраняются и в обычном режиме. Расшифровка может занимать больше времени; режим не гарантирует бесшумную работу вентиляторов.

Для применения новой обработки к старой встрече выберите «Расшифровать заново…» в меню записи. Текст и ручная разметка будут заменены после подтверждения.

WebRTC audio processing 2.1: https://freedesktop.org/software/pulseaudio/webrtc-audio-processing/ (BSD), Abseil (Apache 2.0). Silero VAD: https://github.com/snakers4/silero-vad (MIT), ONNX из официального выпуска sherpa-onnx. Лицензии входят в сборку.

## Интерфейс · 0.3.1

В приложении используется системный шрифт macOS.

Мини-панель открывается по иконке в строке меню или сочетанием ⌘⇧R. Во время записи рядом с иконкой отображается длительность в формате ММ:СС; начиная с часа формат меняется на ЧЧ:ММ:СС. Основное окно можно закрыть и снова открыть из мини-панели.

Колесо мыши вверх/вниз над лентой собеседников прокручивает её влево/вправо. Горизонтальные жесты трекпада поддерживаются.

Геометрия логотипа хранится в Resources/BrandMark.json: из неё создаются иконка приложения и знак строки меню. Рядом с названием в основном окне знак отображается на прозрачном фоне.

## Интерфейс · 0.3.2

Интерфейс использует белые поверхности, светло-серый сайдбар и контрастные тёмные подписи без стеклянных эффектов и цветных акцентов. Единое оформление применяется к основному окну, настройкам, редакторам и мини-панели. Записи системного звука получают название «Созвон», импортированные файлы — «Запись»; дата и время остаются в названии, а пользовательские названия сохраняются. Год появляется только у записей возрастом от календарного года. Карточки в сайдбаре занимают не более двух строк: название и метаданные.

Мини-панель использует текст на один пункт меньше и компактный чекбокс автоматического старта и стопа. В сайдбаре записываемая встреча отмечается красной точкой, надписью «Идёт запись» и живым таймером. Счётчики переходят с ММ:СС на ЧЧ:ММ:СС при достижении часа.

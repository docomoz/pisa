# Семейства аббревиатур

Пользователь сохраняет одно основное написание аббревиатуры. Распознавание, словарь и разметка используют общие правила принадлежности словоформ к термину. Начальный объём — цифровые, латинские и кириллические аббревиатуры с русскими окончаниями; произвольные имена и полная морфология не входят в этот этап.

## Подход

Выбран общий механизм семейств. Простая группировка кандидатов оставила бы разные правила распознавания и потерю окончаний при замене. Универсальная морфология требует отдельной проверки неоднозначных склонений.

Общее представление хранит основное написание и наблюдаемое окончание. Выводимые словоформы не становятся отдельными записями словаря. Явные конкурирующие записи имеют приоритет, неоднозначные соответствия не исправляются автоматически. Исходный строковый формат словаря сохраняется.

## Поведение

- Распознавание сохраняет наблюдаемое окончание: `2GISом → 2ГИС'ом`, если основное написание в словаре — `2ГИС`.
- Окончания цифровых и иностранных аббревиатур выводятся с апострофом; у обычных кириллических сокращений сохраняется слитная запись. Отсутствующее окончание не добавляется по предлогу или по словарю; существующая акустическая проверка сохраняет свои защитные условия.
- Фонетически распознанные формы аббревиатур также сохраняют окончание; короткие конкурирующие аббревиатуры не сливаются.
- Неизвестные однозначные формы группируются по основе. Обычные слова, ссылки, код и защищённые цитаты не изменяются.
- Правильные формы известного термина исключаются из новых кандидатов, но доступны через поиск основы.
- При исправлении основы каждое употребление получает собственную замену с сохранённым окончанием. Предварительный просмотр совпадает с фактической заменой. Буквальный поиск полной формы сохраняется.
- В словарь из разметки добавляется основа. Явные старые записи не удаляются автоматически.

## Проверка

Регрессионные проверки покрывают разные аббревиатуры, смешанные окончания, латинские варианты окончания у цифровых аббревиатур, апострофы, фонетические варианты, повторное применение, конфликты словаря, защищённый текст, точный поиск и отмену. После сборки проверяется действующий экран разметки с прокруткой, предварительным просмотром и клавиатурным фокусом. Строковые проверки не считаются доказательством точности распознавания звука.

# Управление сохранёнными голосами

## Согласованное поведение

В настройках нужна вкладка «Голоса»: список людей, прослушивание сохранённых образцов, переименование и «Забыть голос» с подтверждением. Имена в старых расшифровках сохраняются при обеих операциях.

Отдельная вкладка настроек даёт доступ ко всей библиотеке голосов независимо от выбранной встречи. Управление только внутри разметки встречи затрудняет поиск; отдельное окно добавляет лишнюю навигацию.

## Устройство

- `SavedVoicesSettings.swift`: список, пустое состояние, кнопки образцов, редактор имени, подтверждение удаления и сообщения об ошибках.
- `SettingsView.swift`: новая вкладка «Голоса» между «Модель» и «Экспорт».
- `AppState.swift`: переименование только профиля с сохранением его идентификатора и образцов; удаление профиля и его отдельных аудиообразцов. Состояние меняется после успешного сохранения файла голосов.
- `VoiceProfileTests.swift`: проверки на временной библиотеке и изолированное окно для визуальной проверки.
- `Launcher.swift`: запуск проверки голосов и окна проверки по отдельным аргументам.

Пустое имя и имя другого профиля, совпадающее без учёта регистра, не принимаются. Профили не объединяются. Для старого профиля без аудио доступно пояснение. Каждый сохранённый аудиообразец можно прослушать и остановить. Удаление проигрываемого голоса останавливает звук; уход со вкладки также останавливает прослушивание.

## Ограничения

- SwiftUI, macOS 15, существующее локальное хранилище; без новых зависимостей.
- Все интервалы из `PisyaDesign.Spacing`, заголовки через `SectionHeading`.
- Клавиатурный фокус обозначается заливкой, без внешней рамки.
- Встречи и их экспорт не перезаписываются при управлении профилем.
- В коммит входят только изменения этой задачи; исходные незавершённые изменения рабочей папки сохраняются отдельно.

При визуальной проверке обнаружено, что обычная область прокрутки не следует за фокусом кнопки. Добавлены идентификаторы строк, отслеживание клавиатурного фокуса и переход к нужному человеку. Повторная проверка прошла от первого до двенадцатого человека, включая все десять образцов первого голоса. Проверка изменений не выявила блокирующих замечаний.

## Случаи для итоговой проверки

1. Ошибка записи не меняет профиль в памяти и не удаляет его образцы.
2. Переименование и удаление не меняют файлы активных встреч и корзины.
3. Длинные имена и десять образцов не обрезают кнопки и остаются доступны с клавиатуры.
4. Пустая библиотека объясняет, как сохранить голос из разметки встречи.
5. Отмена редактора и подтверждения оставляет данные прежними.

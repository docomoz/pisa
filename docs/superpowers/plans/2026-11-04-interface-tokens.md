# Общие стили интерфейса

**Цель:** убрать произвольные кегли и интервалы из экранов и закрепить повторяющиеся сочетания в компонентах.

**Основа:** `docs/design-system.md` и правила `AGENTS.md`.

**Подход:** расширить существующую `PisyaDesign`, сохранив текущую иерархию интерфейса. Для заголовков использовать варианты вместо числового размера; пояснения, поля и редакторы получают собственный стиль. Нативное меню сохраняет системную типографику macOS.

- [x] Собрать типографические роли и шкалу интервалов, заменить ручные значения во всех экранах
- [x] Объединить заголовки, секции, поиск, редакторы, подписи и оформление диалогов
- [x] Подключить к сборке проверку прямого задания шрифтов и интервалов вне дизайн-системы
- [x] Собрать приложение, проверить все экраны, раскрытие и прокрутку, Tab и Shift+Tab
- [x] Обновить описание системы и сохранить только изменения задачи в коммите

Проверить особенно длинные подписи, настройки в двух колонках, состояние голосов до и после выбора, отключённые кнопки, фокус основных действий. Сохранять изменения других задач отдельно.

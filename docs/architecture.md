# Pisya

Нативное приложение для macOS 15 и новее, Apple Silicon. Основной сценарий — запись онлайн-встреч в Контур Толке. Библиотека, аудио и обработка находятся на компьютере пользователя.

## Границы доступа

Приложение работает в App Sandbox без разрешений network.client и network.server. Локальная модель читается с диска. Установка модели выполняется отдельно. Загрузка моделей и сборочных зависимостей требует интернета; распознавание — нет.

Экспорт в выбранную папку разрешается пользователем. Если папка обслуживается Dropbox, iCloud или другим сервисом синхронизации, этот сервис получает текст. Аудио автоматически не экспортируется.

MCP работает как отдельный процесс через stdio, без сетевого порта. По умолчанию доступ выключен. Каждый запрос перепроверяет переключатель. Доступны только список встреч, поиск и чтение текста; аудио и изменение данных не доступны через протокол. Подключённый клиент может отправить прочитанный текст своему провайдеру. MCP не защищает данные от других программ, уже имеющих прямой доступ к пользовательским файлам.

## Запись

ScreenCaptureKit получает весь системный звук, кроме собственного процесса; отдельная AVCaptureSession записывает микрофон. CAF-дорожки синхронизируются по временным меткам macOS. Видео не сохраняется. Захват не зависит от запуска Толка, браузера или другого клиента звонков; запись можно начать заранее.

Перед распознаванием микрофона WebRTC AEC3 использует системную дорожку как опорный сигнал. Выравнивание учитывает изменения задержки. Исходники не переписываются; обработка создаёт отдельный производный файл. Эффективность зависит от акустики и устройств.

Микрофон распознаётся без текстовой подсказки и словаря встречи. Автоматический первый проход может определить отсутствие речи. Для коротких фрагментов язык читается из явного ответа модели, без подстановки запасного значения. Фрагменты до полутора секунд с явно определённым другим языком могут повторно проверяться как русская речь; пустой результат, `None` и неизвестный язык второй проход не запускают. Этот режим рассчитан на русскоязычные звонки: короткая настоящая иностранная реплика может быть интерпретирована по-русски.

При отмене короткого распознавания его производитель сначала завершается, затем освобождается модель. Новый проход не начинается одновременно с предыдущим отменённым проходом.

Автодетект опрашивает аудиопроцессы Core Audio раз в две секунды. Использование микрофона другим приложением запускает трёхсекундное ожидание, неактивность — 45-секундное ожидание завершения. Только воспроизведение звука не является триггером. Для заранее начатой ручной записи автостоп включается после обнаружения активности. Ручная остановка подавляет новый старт до окончания активности. Использование микрофона не гарантирует звонок: диктовка и тест устройства могут давать ложные сигналы; отключение микрофона при mute может вызвать автостоп. Режим выключен по умолчанию и требует проверки на реальных звонках.

## Данные

Каждая встреча хранится отдельным JSON-файлом, запись атомарная. Аудио хранится отдельно. Имена файлов создаются из UUID; экспорт использует стабильное имя по UUID и обновляет его после правок. Исходные пользовательские аудиофайлы при импорте копируются, а не перемещаются.

Обработка сериализована: одна модель и одна встреча одновременно. Во время записи обрабатываются подтверждённые участки, модель используется повторно. Черновик и граница обработанного аудио сохраняются атомарно. После остановки обрабатывается оставшийся хвост и уточняется разметка участников, затем модель освобождается. Обработку можно приостановить отдельно от записи. При сильном нагреве она откладывается. При отсутствии подтверждённого системного аудио или безопасной границы длинной реплики черновик может ждать завершения записи.

Silero определяет речь на микрофонной дорожке. Pyannote выделяет речевые области собеседников, TitaNet вычисляет голосовые признаки. Имена сохраняются в профили только отдельным действием пользователя; неоднозначные совпадения не присваиваются автоматически. После перезапуска незавершённый хвост остаётся доступен для продолжения, исходное аудио сохраняется.

## Поставка

Исходники — в публичном репозитории `docomoz/pisya`. MLX Audio подключён как открытый подмодуль на фиксированном коммите; необходимое изменение зависимости MLXFFT хранится отдельным патчем и применяется скриптом сборки. Локальная сборка подписана постоянным локальным сертификатом; идентичность приложения привязана к сертификату. Ключ хранится отдельно от репозитория. Для удобной передачи другим пользователям потребуется подпись Developer ID и notarization; отсутствие этой подписи нельзя считать гарантией безопасности.

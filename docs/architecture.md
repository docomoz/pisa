# Пися

Нативное приложение для macOS 15 и новее, Apple Silicon. Основной сценарий — запись онлайн-встреч в Контур Толке. Библиотека, аудио и обработка находятся на компьютере пользователя.

## Границы доступа

Приложение работает в App Sandbox с разрешением network.client для загрузки моделей. Разрешение network.server отсутствует. При первой настройке нативный URLSession загружает файлы с Hugging Face; распознавание выполняется локально. Аудио и расшифровки для распознавания не отправляются.

Комплект моделей задаётся встроенным manifest с размерами и SHA-256. Каждый файл загружается во временный файл, проверяется потоком вне главного потока и атомарно заменяет целевой файл. Отмена прерывает загрузку и проверку, удаляя незавершённый файл; готовые файлы используются повторно. Перед загрузкой проверяется свободное место. При запуске проверяется полный комплект, включая модели участников. Пользовательская папка MLX поддерживается через security-scoped bookmark; для неё проверяется структура, без привязки весов к хешам стандартной модели.

Пока окно первой настройки открыто или идёт загрузка, ручная и автоматическая запись не начинаются. «Позже» разрешает сохранять аудио без расшифровки. Разрешения микрофона и системного звука запрашиваются существующим сценарием при первой записи.

Экспорт в выбранную папку разрешается пользователем. Если папка обслуживается Dropbox, iCloud или другим сервисом синхронизации, этот сервис получает текст. Аудио автоматически не экспортируется.

MCP работает как отдельный процесс через stdio, без сетевого порта. По умолчанию доступ выключен. Каждый запрос перепроверяет переключатель. Доступны только список встреч, поиск и чтение текста; аудио и изменение данных не доступны через протокол. Подключённый клиент может отправить прочитанный текст своему провайдеру. MCP не защищает данные от других программ, уже имеющих прямой доступ к пользовательским файлам.

## Запись

ScreenCaptureKit получает весь системный звук (кроме собственного процесса) и микрофон в отдельные CAF-дорожки. Сохраняется разница временных меток начала дорожек. Видео не сохраняется. Захват не зависит от запуска Толка, браузера или другого клиента звонков; запись можно начать заранее.

Автодетект опрашивает аудиопроцессы Core Audio раз в две секунды. Использование микрофона другим приложением запускает трёхсекундное ожидание, неактивность — 45-секундное ожидание завершения. Только воспроизведение звука не является триггером. Для заранее начатой ручной записи автостоп включается после обнаружения активности. Ручная остановка подавляет новый старт до окончания активности. Использование микрофона не гарантирует звонок: диктовка и тест устройства могут давать ложные сигналы; отключение микрофона при mute может вызвать автостоп. Режим выключен по умолчанию и требует проверки на реальных звонках.

## Данные

Каждая встреча хранится отдельным JSON-файлом, запись атомарная. Аудио хранится отдельно. Имена файлов создаются из UUID; экспорт использует стабильное имя по UUID и обновляет его после правок. Исходные пользовательские аудиофайлы при импорте копируются, а не перемещаются.

Обработка сериализована: одна модель и одна встреча одновременно. После завершения модель освобождается. Pyannote выделяет речевые области, TitaNet вычисляет голосовые признаки. Имена сохраняются в профили только отдельным действием пользователя; неоднозначные совпадения не присваиваются автоматически. Незавершённые обработки при запуске помечаются для повторения, исходное аудио остаётся доступным.

После полной расшифровки Qwen3-1.7B-4bit формулирует короткое название по содержанию беседы. Длинный текст последовательно сворачивается в промежуточные выжимки; обрабатываются все части, включая завершение встречи. Модель названий загружается однократно по отдельному manifest с проверкой размера и SHA-256, затем работает локально. Текст встречи не передаётся серверу загрузки моделей.

Источник названия сохраняется в JSON. Название, заданное человеком, не заменяется при повторной обработке; смысловое название не сбрасывается в дату при запуске приложения. Расшифровка сохраняется до генерации названия: ошибка этой дополнительной операции оставляет готовый текст и прежнее название.

## Поставка

`scripts/build.sh` создаёт приложение и DMG с Applications, фоновым изображением и стрелкой переноса. В приложение включены нативные динамические библиотеки, Metal-ресурсы, помощник MCP и лицензии. Python, Homebrew и Xcode на Mac пользователя не требуются.


MLX Audio подключён как открытый подмодуль на фиксированном коммите. Скрипт упаковки использует идентичность из локального файла `.signing.env`, если она настроена; иначе применяется ad-hoc подпись. Ключи и параметры личного сертификата не включаются в репозиторий. Проверка целостности подписи выполняется после добавления библиотек, помощника MCP и лицензий. Подпись Developer ID и нотариальное заверение Apple нужны для обычного распространения на другие Mac; текущая локальная сборка не объявляется нотариально заверенной.
